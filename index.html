Connect to GitHub

Status changes here save straight to the cmcdatasolutions/compliance_remediation GitHub repo, so everyone sees the same live data. Paste a GitHub personal access token with read/write access to that repo — it's stored only in this browser tab for this session, and is never sent anywhere except directly to GitHub.

About this dashboard. Built from the vendor security assessment questionnaire and cost analysis; statuses for the 31 actionable items come from the internal task tracker's "Open Items" tab, the remaining 42 items are marked "No action required" / "Not applicable" in the source questionnaire and start as Completed. Status changes, added items, and imports save straight to the cmcdatasolutions/compliance_remediation GitHub repo (click 🔗 Connect GitHub above with a repo-scoped token) so everyone sees the same live data — GitHub's commit history doubles as a change log of who updated what and when. Export progress / Import progress remain available as a manual, offline backup. Use + Add item to add a new row to the tracker.
